What is Cloud Computing?

Cloud computing is using computers, storage, and software over the internet instead of only on your own computer.

Cloud Services

  • AWS - used to host websites, servers, and storage.
  • Microsoft Azure - used for virtual machines and business apps.
  • Google Drive - used to store and share files online.
